# Împreună pentru Bobi Simion

A small Romanian-language fundraising tracker built with React and Vite.

```sh
npm install
npm run dev
```

The tracker starts at 1,532 RON and shows progress toward an initial goal of 3,000 RON. Visit `/admin` to set the total, add a contribution, change the goal, edit the public title and description, or switch between the magenta and green themes. The admin page is not password-protected and is accessible to anyone using the app. The total, goal, text, and theme are stored in the current browser's local storage, not synchronized across devices or users; changes appear on the main page in the same browser. Clearing browser data removes the saved values. This app does not process payments.

Run `npm run build`, `npm run lint`, and `npm test` to verify the app.
